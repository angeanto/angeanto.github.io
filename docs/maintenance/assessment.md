# Senior Data Analyst Scorecard

The implementation now lives on `codex/scorecard-current-design`, based on current site commit `1862f31`. The original assessment branch used the older September checkout; it remains untouched to preserve unrelated work. Use this branch/worktree for further assessment changes.

Route: `/senior-data-analyst-scorecard/`. The page inherits `assessment` → `single` → `default`, the current DataConscious masthead/footer and Poppins typography. `author_profile: false` removes the old author sidebar. Classes `wide`, `brand-page`, and `assessment-page` center an 880px reading column. Scoped `_sass/_assessment.scss` uses the current white, warm-neutral, and yellow palette, with readable 16px answer text and native accessible radio inputs. Navigation and other pages are unchanged.

The ten questions and five equally weighted dimensions live in `_data/analyst_assessment.json`. Each best answer earns one point; unknown and incorrect choices earn zero. Scoring is deterministic, with no speed bonus or seniority classifications. Increment the question-bank version when changing question meaning or scoring. `core.js` validates stored state and scores answers; `scorecard.js` renders questions, review, learning guidance, printable explanations, and sharing.

Every result places an Accelerator invitation directly below the overall score. Enrollment uses the shared `checkout_url` in `_data/accelerator.yml`; “Request a 15-minute call” opens the existing on-site `#interest` form; “Explore the programme” opens its overview. This is a call request, not an automatic calendar booking. No checkout or form is submitted by the assessment. Dimension scores and explanations are grouped in a collapsed disclosure. The learning selector, weekly exercise, and reading-resource section have been removed at the owner's request. Copy sharing no longer references a learning focus. Opt-in events distinguish enrollment, call, and exploration clicks; these do not imply completed purchases or bookings.

Answers stay in browser localStorage (`dc-analyst-assessment`). Restart asks before replacing them; unavailable storage should not block completion. No email collection or backend is included. Answer keys are inspectable and scores are not verified credentials. Sharing copies an assessment invitation and the public assessment link; printing expands explanations.

The page is omitted from navigation and sitemap, with `robots: noindex, follow`. Current site search and deployment indexing are disabled. The page disables default analytics and MailerLite loading; Google engagement events require optional consent (`dc-assessment-measurement`). Events contain version/question/dimension identifiers, not answer values or scores. Withdrawal reloads to unload the tag; this is not a site-wide consent system. Live Google delivery is not part of local testing.
